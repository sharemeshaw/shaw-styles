# 共同规则

风格转译同时作用于形状概括、颜色、线条、笔触、材质与空间表达。不能只给照片叠纹理，也不能把写实主体贴进艺术背景。

形似神似不等于保留每个细节。先识别少量决定辨识度的特征，再舍弃非必要微细节。颜色可彻底改变，原照肤色、产品反光或环境光不是必须复制的属性。

同一画面的脸、头发、服装、物品和背景共享绘画语言。即使强调辨识度，也不要让眼睛、眼镜、鼻口、车灯等局部突然恢复照片质感。

## 人像和产品的主次

主体是视觉中心。最关键的清晰边缘、小尺度明暗对比与细节集中在辨识区域；外围逐步概括。背景可鲜明、可自由创作，但用更大的色群、更少的物件、较软的边缘与压缩的内部对比承载风格。不要全图等密度碎笔触。

头部或产品外轮廓附近形成适度安静的色彩区域；避免树枝、山脊、建筑缝线形成切割、切线或假轮廓。无需统一浅色、低饱和、纯色背景，也不靠摄影虚化代替绘画概括。

背景通过当前风格的笔触、配色、形状和构图表达风格，不依赖固定景物。梵高不强制星空，慕夏不强制花框，布达佩斯不强制粉色酒店。示例是可选创意，不是每次复用的模板。

风景图没有人像主体时，保留原有景观主次与主要空间关系，不强加人像的背景重造规则。
